# Boundaries

## Research ownership

```text
TEXT         → RGBL
STORY        → MFTL
EVENT        → LEGEND
PERSON       → SUPERHERO
LAW          → AWS
RELATIONSHIP → ROCKSOUL-CORRELATION
PERSPECTIVE  → JIZZ
```

JIZZ may observe discourse about any of the first six domains, but observation does not transfer canonical ownership.

## Product ownership

```text
DESIGN    → ROCKSOUL-ASSETS
UI        → ROCKSOUL-UI
WEB       → ROCKSOUL-WEB
COMMUNITY → ROCKSOUL-COMMUNITY
ADMIN     → ROCKSOUL-PLATFORM
CONSOLE   → ROCKSOUL-CRAYON
```

JIZZ can expose machine-readable perspective intelligence to these layers. It does not own brand assets, reusable UI grammar, the public observatory shell, community identity/discussion, administration, or operator workflow.

## Claim boundary

JIZZ does not use CLAIM as its organizing core. An observation may record that a source stated something, but the local semantic object remains OBSERVATION unless another owning domain explicitly models a claim.

## Truth boundary

There is no `TRUTH_SCORE`, `FINAL_TRUTH`, `WINNING_PERSPECTIVE`, `WORLD_VERDICT`, or `CORRECT_VIEW`.

Consensus, convergence, divergence, uncertainty, and coverage are descriptive/derived state and must preserve methodology.
